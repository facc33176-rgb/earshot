# 拆着用：没有服务器，也能把 Earshot 的本事搬走

Earshot 是一整套能跑的电话，但它最值钱的不是服务器，而是几条「怎么像人一样打电话」的做法。这些做法大多是**纯文字规则**或者**几十行不依赖任何库的小函数**，可以单独拿走，放进你已经在用的前端（Kelivo、Operit、SillyTavern、自己写的 App……），跟你原来的人设和记忆一起用。

> 你在跟谁谈恋爱，就让谁来打电话。不用换人，把下面这些交给 TA 用的那个前端就好。

## 一、什么都不用装：只抄规则

下面这些直接写进系统提示词就有用，不需要任何代码。原文在 `server/prompt.js`：

| 想要的效果 | 拿哪段 | 说明 |
|---|---|---|
| 像打电话一样说话 | `CALL_STYLE` | 第一句要短，不用 markdown，情绪跟着对方走…… |
| 声音带情绪 | `VOICE_TAGS` | 告诉模型可以用 `[laughs]` `[sighs]` 这类标记（ElevenLabs v3/v4 才会念出来，别的声音要把标记删掉） |
| 不乱挂、不硬挂 | `HANGUP` | 对方认真要走才挂，`[[hangup]]`；对方难过就 `[[stay]]` |
| 没说完就等一等 | `MAYBE_UNFINISHED` | 对方话说一半，模型只回 `[[wait]]`，前端接着听 |
| 安静时自己找话说 | `idleNote()` | 安静了 1、2、3 分钟，各给模型一句提示，语气慢慢变 |

另外，**怎么写语气标记**单独整理成了一份规则：见「语气小抄 Say It Like You Mean It」。

## 二、会一点代码：拿走小函数

全部是原生 JavaScript，没有依赖，复制文件就能用。

| 文件 | 管什么 | 主要用法 |
|---|---|---|
| `web/lib/turn.mjs` | 话轮：什么时候算说完 | `QUICK_PAUSE_MS`（0.8 秒先交）、`PATIENT_PAUSE_MS`（等一等 2.2 秒）、`isWait()`、`joinSaid()`（两截话拼起来） |
| `web/lib/speech.mjs` | 边写边念 | `takeSentences()` 从流式文字里切出完整句子，一句一句送去念；`segmentPause()` 句子之间停多久 |
| `web/lib/idle.mjs` | 安静的时候 | `idlePlan()` 白天/夜里的时间表；`idleSound()` 小动静（嗯、哼一声、轻咳）；`askedToWait()` 听出「等一下」 |
| `web/lib/gate.mjs` | 听出有人在说话 | 跟着房间噪音自动调门槛，叹气、小声说话算数，短促杂音不算；用来判断该不该打断、该不该接着听 |
| `server/tags.js` | 藏起控制标记 | 把 `[[hangup]]` `[[stay]]` 从要念的文字里去掉，同时告诉前端 |
| `server/hedge.js` | 模型太慢 | 第一个模型 6 秒没出字，就同时问第二个，谁先开口用谁 |

## 三、和记忆接上

电话最怕「换了一个人」。不管你用哪个前端，记得做两件事：

1. **打电话前**：把人设和最近的记忆一起放进系统提示词（Earshot 里是 `persona.md`，你那边就是原来的角色卡）。如果你的前端接了记忆 MCP，电话也连同一个。
2. **挂电话后**：把这通电话的文字记录（或者一段小结）存回记忆，或者粘回聊天里。这样 TA 下次聊天时知道你们刚打过电话。

## 四、懒人做法：交给你的 AI

把下面这段连同整个仓库（或者上面提到的几个文件）一起发给你常用的、会写代码的 AI：

```
这是一个叫 Earshot 的开源 AI 电话项目（MIT）。我没有服务器，想把它的电话做法
接进我现在用的 ______（填前端名字）里，继续用我原来的人设和记忆。
请你：
1. 把 server/prompt.js 里的 CALL_STYLE、HANGUP、MAYBE_UNFINISHED 改写成适合我前端的系统提示词；
2. 看我的前端能不能接入 web/lib/ 里的 turn / speech / idle 这几个小函数（不能接就只用提示词部分）；
3. 告诉我哪些功能在我的前端里做不到，不要假装做到了。
```
