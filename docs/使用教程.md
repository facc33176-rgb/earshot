# Earshot 使用教程

Earshot（听着呢）是一个能和 AI 打电话的小程序：你在网页上点一下绿色按钮，就像打电话一样跟它说话。它跟一般的 AI 语音不一样的地方：

- 你一开口它就在听，停顿一下就交给模型，由模型判断你说完没有；
- 你话没说完，它会等你接着说，然后把几截话接成一句；
- 它说话时你点一下波形就能打断，它马上停；它还在想的时候你接着说，它会放弃那句回答，继续听你；
- 回答慢的时候会轻轻"嗯"一声；你一直不说话，它会哼歌、咳嗽、自言自语，过几分钟自己找话说，很久没动静才道别挂断，夜里会更轻。

整个程序就是一个不需要安装依赖的 Node 服务器加一个网页。下面从零开始，一步步跑起来。

仓库地址：**https://github.com/facc33176-rgb/earshot**

---

## 使用须知（先看这个）

- **要花钱。** 每打一通都用你自己的钥匙和额度，程序本身不带免费额度。
- **它是 AI。** 别拿它冒充真人去骗不知情的人，也别用它去联系没同意的人。
- **说的话会发出去。** 你的声音发给转文字服务，文字发给大模型，回答发给声音服务。Earshot 自己不存任何聊天记录。
- **上网前一定设口令**，不然谁拿到网址都能用你的额度打电话。安装向导会自动帮你生成一个。
- 不能用于急救、医疗、法律咨询或心理危机求助。软件按 MIT 协议免费提供，不做任何保证。

## 一、拿钥匙

打电话需要三样东西：会想的（大模型）、会听的（转文字）、会说的（声音）。安装向导准备了三套现成搭配，选一套，照着去拿钥匙就行：

| 选项 | 想 | 听 | 说 | 要几把钥匙 | 去哪拿 |
|---|---|---|---|---|---|
| 1 | OpenAI | OpenAI Whisper | OpenAI 语音 | 1 | platform.openai.com → API keys |
| 2 **国内推荐** | DeepSeek | 硅基流动 SenseVoice | 硅基流动 CosyVoice | 2 | platform.deepseek.com、cloud.siliconflow.cn |
| 3 **声音最有感情** | OpenAI（可换别家） | OpenAI Whisper | ElevenLabs | 2～3 | 外加 elevenlabs.io |

选 2 不用翻墙，两家都能用支付宝充值，充几十块能打很久。选 3 声音最像真人，会笑、会叹气，但 ElevenLabs 要海外银行卡。

**ElevenLabs 声音 ID 在哪：** 登录 → Voices → 选一个声音（或用 Voice Design 自己设计一个）→ 点开复制 Voice ID。钥匙在头像 → API Keys。

## 二、安装（三选一，都会进同一个安装向导）

先装 [Node.js](https://nodejs.org)（20 版或更新，官网下载点下一步就行）。不用装别的。

**A. 自己电脑，双击就行（最简单）**

1. 下载压缩包：https://github.com/facc33176-rgb/earshot/archive/refs/heads/main.zip ，解压。
2. 苹果电脑双击 `start.command`；Windows 双击 `start.bat`。
   （苹果第一次可能提示"无法验证开发者"：右键 → 打开 → 再点打开。）
3. 第一次会出现安装向导，回答几个问题；结束后浏览器自动打开通话页。

**B. 服务器，一行命令**

```bash
curl -fsSL https://raw.githubusercontent.com/facc33176-rgb/earshot/main/install.sh | bash
```

它会下载到 `~/earshot`、跑安装向导、检查钥匙；装了 pm2 的话直接在后台跑起来。

**C. 手动**

```bash
git clone https://github.com/facc33176-rgb/earshot.git
cd earshot
npm run setup
npm start
```

### 安装向导会问什么

1. 选哪套搭配（上面的 1、2、3，或者 4 自己改配置）；
2. 填钥匙（粘贴进去回车）；
3. 它叫什么名字；
4. 说中文还是英文（zh / en）；
5. 要不要用手机或外网打：选 y 会自动生成一个口令并显示出来，记下来。

问完它会自动用你的钥匙发三个很小的真实请求：让模型说句话、让声音念一句、把念的声音再转回文字。三行都打勾就是成功了；打叉的那行后面会写原因，多半是钥匙复制错了。想改答案就再跑一次 `npm run setup`，直接回车会保留原来的值。

### 改人设

安装向导会生成 `persona.md`，用记事本打开就能改：它的名字、性格、你们怎么认识、你们之间的梗、怎么称呼你。写大白话就行，每一轮对话模型都会先读一遍，改完马上生效，不用重启。

## 三、在电脑上先打一通

启动后（双击启动，或者 `npm start`），打开 http://localhost:8787 ，点绿色按钮，允许用麦克风，就可以说话了。

通话界面：

- 中间两条光线，珊瑚色是你，白色是它；
- 它说话时**点一下光线就是打断**；
- 左下是静音，右边红色是挂断；
- 最下面那行小字是这一轮从你说完到它出声用了几秒。

## 四、用手机打

浏览器规定：只有 `https://` 开头的网址（或者本机 localhost）才能用麦克风。所以手机要用，得给电脑或服务器上的 Earshot 一个 https 地址。最省事的是 Cloudflare 的免费隧道：

```bash
# 先装 cloudflared（官网有各系统的安装包），然后：
cloudflared tunnel --url http://localhost:8787
```

它会打出一个 `https://xxxx.trycloudflare.com` 的地址，手机打开就能打电话。这个地址每次重开都会变；想要固定地址，可以用自己的域名配一个正式的 Cloudflare Tunnel，或者在有域名的服务器上用 Caddy：`caddy reverse-proxy --from call.你的域名 --to localhost:8787`。

**放到网上之前一定要有口令。** 安装向导里选了 y 就已经有了（就是向导最后显示的那串字，也写在 `.env` 的 `ACCESS_TOKEN=` 后面）。手机第一次打开网页，点 Settings 填进去，之后就记住了。

**iPhone 小技巧：** Safari 打开网址 → 分享 → 添加到主屏幕，桌面上就有一个像 App 的图标。记得关掉手机侧面的静音开关，不然听不到声音。

## 五、让它一直开着

电脑关了它就停了。想放在服务器上一直跑：

```bash
npm install -g pm2
pm2 start server/index.js --name earshot
pm2 save && pm2 startup   # 开机自己启动
```

改了 `.env` 之后：`pm2 restart earshot`。以后更新到新版本：`cd ~/earshot && git pull && pm2 restart earshot`。

## 六、网页里的设置

点首页的"Settings"：

- **Access token**：上面说的口令；
- **用浏览器自带的听写**：Chrome、Edge、安卓上可以用浏览器自己的语音识别，免费、快。但声音会发给谷歌或微软，国内多半连不上，连不上会自动换回录音转文字；
- **说话就能打断**：开着以后，它说话时你大声说话也能打断它。外放的时候它可能被自己的声音打断，所以建议戴耳机再开。点光线打断一直都能用。

## 七、想改得更像你们

- **电话里怎么说话**：`server/prompt.js`，里面是"第一句要短""别用列表""跟着气氛走"这些规矩，中英文各一份；
- **等的时候那声"嗯"**：`server/fillers.js`；
- **没人说话时的小动静和时间**：`web/lib/idle.mjs`，30 秒先出点动静，之后每分钟左右自己说两句，白天 7 分钟、夜里 5 分钟没动静才道别；
- **停多久算说完**：`web/lib/turn.mjs` 最下面几个数字。你说话爱停顿、总被抢话，就把 `QUICK_PAUSE_MS` 调大一点。

## 八、常见问题

**提示麦克风被拦了**
网址必须是 https 或 localhost，并且要在浏览器设置里允许这个网站用麦克风。

**iPhone 上没声音**
关掉侧面静音开关、调大音量。网页的声音会跟着静音开关走。

**我还没说完它就抢着回答**
调大 `web/lib/turn.mjs` 里的 `QUICK_PAUSE_MS`（默认 800 毫秒）；或者换一个更听话的模型，它要会回 `[[wait]]`。

**它老是自己打断自己**
关掉"说话就能打断"，或者戴耳机。

**出声很慢**
`npm run check` 会显示每一步花了多久。多数时间花在模型想第一个字、声音生成第一句上。可以换更快的模型，把 `ELEVENLABS_MODEL` 换成 `eleven_flash_v2_5`（更快但没那么有感情），或者设一个 `LLM_BACKUP_MODEL`：第一个模型 6 秒还没开口，就同时问第二个，谁先开口用谁。

**想看它每一步在干什么**
在浏览器控制台输入 `localStorage.setItem('earshot:debug','1')`，再打一通，控制台里会打出每一步的时间。

**会不会存我的聊天记录**
Earshot 自己什么都不存，挂了电话这通的内容就没了（只缓存那几声"嗯"的音频）。但你的声音会发给转文字服务、文字会发给大模型、回答会发给声音服务，各家怎么处理数据要看它们自己的条款。

**花多少钱**
默认配置下，模型每分钟不到一分钱人民币；Whisper 约每分钟 0.04 元（只算你说话的时长）；ElevenLabs 按念出来的字数扣额度，聊得多的一分钟大约 600 到 900 个字符。
