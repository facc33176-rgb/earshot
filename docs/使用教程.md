# Earshot 使用教程

Earshot（听着呢）是一个能和 AI 打电话的小程序：你在网页上点一下绿色按钮，就像打电话一样跟它说话。它跟一般的 AI 语音不一样的地方：

- 你一开口它就在听，停顿一下就交给模型，由模型判断你说完没有；
- 你话没说完，它会等你接着说，然后把几截话接成一句；
- 它说话时你点一下波形就能打断，它马上停；它还在想的时候你接着说，它会放弃那句回答，继续听你；
- 回答慢的时候会轻轻"嗯"一声；你一直不说话，它会哼歌、咳嗽、自言自语，过几分钟自己找话说，很久没动静才道别挂断，夜里会更轻。

整个程序就是一个不需要安装依赖的 Node 服务器加一个网页。下面从零开始，一步步跑起来。

---

## 一、准备三把钥匙

打电话需要三样东西：会想的（大模型）、会说的（声音）、会听的（转文字）。每样都要一把"钥匙"（API Key）。

| 用途 | 推荐 | 说明 |
|---|---|---|
| 大模型 | OpenAI、DeepSeek、OpenRouter 等 | 只要是"OpenAI 兼容"的接口都能用 |
| 声音 | ElevenLabs | 最有感情，认识 `[笑]` 这类语气标记；也可以换成任何 OpenAI 兼容的语音合成 |
| 转文字 | OpenAI Whisper、Groq | 任何 OpenAI 兼容的 `/audio/transcriptions` |

**在国内的话**可以这样搭：

- 大模型用 DeepSeek：`LLM_BASE_URL=https://api.deepseek.com/v1`，`LLM_MODEL=deepseek-chat`；
- 转文字和声音都可以用硅基流动（SiliconFlow），它提供 OpenAI 兼容的转文字（SenseVoice）和语音合成（CosyVoice）接口。具体模型名和音色名以它的官方文档为准；
- ElevenLabs 声音最好听，但付费要海外银行卡。

**ElevenLabs 的声音 ID 在哪：** 登录 ElevenLabs → Voices → 选一个声音（或者用 Voice Design 自己设计一个）→ 点开详情，复制 Voice ID。钥匙在头像 → API Keys。

---

## 二、下载和填配置

1. 安装 [Node.js](https://nodejs.org)（20 版或更新）。装好后在终端输入 `node -v`，能看到版本号就行。
2. 下载这个仓库（GitHub 页面上 Code → Download ZIP，解压），终端进入这个文件夹。
3. 复制两份模板：

```bash
cp .env.example .env
cp persona.example.md persona.md
```

4. 用记事本打开 `.env`，至少填这几行：

```ini
LLM_API_KEY=你的大模型钥匙
ELEVENLABS_API_KEY=你的 ElevenLabs 钥匙
ELEVENLABS_VOICE_ID=你选的声音 ID
STT_API_KEY=转文字的钥匙（和大模型是同一家 OpenAI 的话可以留空）
```

用别家的服务就把对应的 `..._BASE_URL` 和 `..._MODEL` 一起改掉。每一行在 `.env.example` 里都有说明。

5. 打开 `persona.md`，写它是谁：名字、性格、你们怎么认识、你们之间的梗、怎么称呼你。写成大白话就行，每一轮对话模型都会先读它。

---

## 三、自检

```bash
npm run check
```

它会用你的钥匙真的发三个很小的请求：让模型说句话、让声音念一句、再把念出来的声音转回文字。三行都打勾就说明配置对了；哪一行打叉，后面会写原因（多半是钥匙填错，或者网址、模型名不对）。

---

## 四、启动，先在电脑上打一通

```bash
npm start
```

看到 `Earshot is listening on http://localhost:8787` 后，用 Chrome 或 Safari 打开这个地址，点绿色按钮，允许使用麦克风，就可以说话了。

通话界面：

- 中间两条光线，珊瑚色是你，白色是它；
- 它说话时**点一下光线就是打断**；
- 左下是静音，右边红色是挂断；
- 最下面那行小字是这一轮从你说完到它出声用了几秒。

---

## 五、用手机打

浏览器规定：只有 `https://` 开头的网址（或者本机 localhost）才能用麦克风。所以手机要用，得给电脑或服务器上的 Earshot 一个 https 地址。最省事的是 Cloudflare 的免费隧道：

```bash
# 先装 cloudflared（官网有各系统的安装包），然后：
cloudflared tunnel --url http://localhost:8787
```

它会打出一个 `https://xxxx.trycloudflare.com` 的地址，手机打开就能打电话。这个地址每次重开都会变；想要固定地址，可以用自己的域名配一个正式的 Cloudflare Tunnel，或者在有域名的服务器上用 Caddy：`caddy reverse-proxy --from call.你的域名 --to localhost:8787`。

**放到网上之前一定要设口令。** 在 `.env` 里填 `ACCESS_TOKEN=随便一串只有你知道的字`，重启。网页第一次会让你在"Settings"里填这个口令，之后就记住了。不设的话，谁拿到网址都能用你的额度打电话。

**iPhone 小技巧：** Safari 打开网址 → 分享 → 添加到主屏幕，桌面上就有一个像 App 的图标。记得关掉手机侧面的静音开关，不然听不到声音。

---

## 六、让它一直开着

电脑关了它就停了。想放在服务器上一直跑：

```bash
npm install -g pm2
pm2 start server/index.js --name earshot
pm2 save && pm2 startup   # 开机自己启动
```

改了 `.env` 或 `persona.md` 之后：`pm2 restart earshot`（`persona.md` 其实每轮都会重新读，改完不重启也行）。

---

## 七、网页里的设置

点首页的"Settings"：

- **Access token**：上面说的口令；
- **用浏览器自带的听写**：Chrome、Edge、安卓上可以用浏览器自己的语音识别，免费、快。但声音会发给谷歌或微软，国内多半连不上，连不上会自动换回录音转文字；
- **说话就能打断**：开着以后，它说话时你大声说话也能打断它。外放的时候它可能被自己的声音打断，所以建议戴耳机再开。点光线打断一直都能用。

---

## 八、想改得更像你们

- **人设**：`persona.md`，随便写；
- **电话里怎么说话**：`server/prompt.js`，里面是"第一句要短""别用列表""跟着气氛走"这些规矩，中英文各一份；
- **等的时候那声"嗯"**：`server/fillers.js`；
- **没人说话时的小动静和时间**：`web/lib/idle.mjs`，30 秒先出点动静，之后每分钟左右自己说两句，白天 7 分钟、夜里 5 分钟没动静才道别；
- **停多久算说完**：`web/lib/turn.mjs` 最下面几个数字。你说话爱停顿、总被抢话，就把 `QUICK_PAUSE_MS` 调大一点。

---

## 九、常见问题

**提示麦克风被拦了**
网址必须是 https 或 localhost，并且要在浏览器设置里允许这个网站用麦克风。

**iPhone 上没声音**
关掉侧面静音开关、调大音量。网页的声音会跟着静音开关走。

**我还没说完它就抢着回答**
调大 `web/lib/turn.mjs` 里的 `QUICK_PAUSE_MS`（默认 800 毫秒）；或者换一个更听话的模型，它要会回 `[[wait]]`。

**它老是自己打断自己**
关掉"说话就能打断"，或者戴耳机。

**出声很慢**
`npm run check` 会显示每一步花了多久。多数时间花在模型想第一个字、声音生成第一句上。可以换更快的模型，把 `ELEVENLABS_MODEL` 换成 `eleven_flash_v2_5`（更快但没那么有感情），或者设一个 `LLM_BACKUP_MODEL`：第一个模型 6 秒还没开口，就同时问第二个，谁先开口用谁。

**想看它每一步在干什么**
在浏览器控制台输入 `localStorage.setItem('earshot:debug','1')`，再打一通，控制台里会打出每一步的时间。

**会不会存我的聊天记录**
Earshot 自己什么都不存，挂了电话这通的内容就没了（只缓存那几声"嗯"的音频）。但你的声音会发给转文字服务、文字会发给大模型、回答会发给声音服务，各家怎么处理数据要看它们自己的条款。

**花多少钱**
默认配置下，模型每分钟不到一分钱人民币；Whisper 约每分钟 0.04 元（只算你说话的时长）；ElevenLabs 按念出来的字数扣额度，聊得多的一分钟大约 600 到 900 个字符。
